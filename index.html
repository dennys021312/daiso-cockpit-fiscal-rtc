Imposto Seletivo (IS) LC 214 Art. 409

Bebidas açucaradas importadas (ex.: Ramune, refrigerantes asiáticos) sofrem incidência adicional de IS na importação e venda.

Alíquota Reduzida / Cesta Básica cClassTrib

Alimentos e itens de higiene exigem mapeamento rigoroso do código cClassTrib para evitar tributação cheia indevida no PDV.

Arredondamento Bancário ADR003

A API oficial usa BigDecimal (8 casas, HALF_EVEN). Diferenças de centavos com o ERP devem ser auditadas por item.

Endpoints Oficiais Mapeados (ReceitaFederal/calculadora-rtc-regime-regular)

Método Endpoint Uso no Cockpit Fiscal Daiso
POST/observabilidade/regime-geralAuditoria de NF-e/NFC-e em lote sem derrubar a nota quando 1 item falha.
POST/base-calculo/base-calculo-unificadaValidação da base unificada (valor produto + frete + seguro + despesas - descontos).
POST/xml/generate?tipo=nfeGeração do trecho XML oficial de tributação (<IBSCBS>) para conferência com o ERP.
POST/xml/validate?tipo=nfe&subtipo=grupoValidação contra o schema XSD oficial antes da autorização na SEFAZ.
GET/dados-abertos/...Consulta de tabelas oficiais de NCM, CST, cClassTrib, alíquotas UF/Mun e fundamentação legal.
GET/observabilidade/erros?codigo=REG-011Dicionário oficial de erros de entrada e inconsistências estruturais.

Kit Completo para Publicação no seu GitHub

Baixe ou copie os arquivos abaixo para criar um repositório profissional com GitHub Pages e Docker Compose pronto para rodar com a API da Receita Federal.

Passo 1

Crie o repositório

No GitHub, crie um novo repo (ex.: daiso-cockpit-fiscal-rtc).

Passo 2

Suba os 4 arquivos

Envie index.html, README.md, docker-compose.yml e LICENSE.

Passo 3

Ative o GitHub Pages

Em Settings → Pages → Branch: main. O sistema fica online em segundos!

Passo 4

Pluge a API da RFB

Quando quiser modo oficial, rode docker compose up -d na rede interna.
